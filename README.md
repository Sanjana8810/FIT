FITBOT – AI-Powered Fitness Assistant

About the Project

FITBOT is an AI-powered fitness chatbot web application designed to provide interactive fitness guidance and personalized workout suggestions.

Features

- AI Fitness Chatbot
- Workout Generator
- Food Scanner
- Live Movement Coach
- Smart Schedule Rebuilder
- Explainable AI Coach
- Virtual Fitness Garden
- Fitness Dashboard
- Weekly Planner
- Workout Timer
- Goals and Achievements
- Fitness Tips

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- AI API Integration

Project Structure

- "app.py" – Main Flask application
- "chatbot.py" – Chatbot functionality
- "food_scanner.py" – Food scanning functionality
- "workout.py" – Workout generation
- "database.py" – Database operations
- "static/" – CSS and JavaScript files
- "templates/" – HTML pages

Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies:

pip install -r requirements.txt

4. Configure your API key in a local ".env" file.
5. Run the application:

python app.py

Security

Never upload API keys, passwords, or private credentials.
